Отчет по администрированию (День 12)

1. Как реализуются роли в SQLite
В SQLite нет встроенных пользователей. Разграничение прав делается на уровне Python-кода: есть таблица roles и словарь PERMISSIONS, который проверяет, что можно делать пользователю с определенной ролью.

2. Функция check_permission
Функция получает user_id и action. Она запрашивает роль пользователя из базы и проверяет, есть ли это действие в списке разрешенных для роли. Результат: reader не может DELETE, admin_db может всё.

3. Способы бэкапа
- shutil.copy: простое копирование файла. Минус: если в момент копирования идет запись, копия может быть битой.
- conn.backup(): безопасный снимок базы, который не ломается при активных транзакциях.

4. PRAGMA integrity_check
Команда проверяет целостность базы. Если всё в порядке, возвращает "ok".

5. Восстановление базы
Для восстановления достаточно скопировать файл бэкапа обратно в db/shoe_store.sqlite (при остановленной программе).
